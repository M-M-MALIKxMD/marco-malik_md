## 🚀 Setup & Deploy Guide

### Step 1 — Clone / Fork Repository

```bash
git clone https://github.com/your-username/marco-malik-md.git
cd marco-malik-md
```

### Step 2 — Install Dependencies

```bash
npm install --legacy-peer-deps
```

### Step 3 — Configure Environment

```bash
cp .env.example .env
```

Edit `.env` file:

```env
BOT_NAME=Marco Malik MD Bot
OWNER_NAME=Marco Malik
OWNER_NUMBER=923001234567
PREFIX=.
MODE=public
OPENAI_API_KEY=sk-your-openai-key
ANTI_CALL=true
AUTO_REACT=true
AUTO_STATUS_READ=true
ANTI_DELETE=true
```

### Step 4 — Get Section ID (Pairing)

> Instead of scanning QR code, you can use pairing code:

1. Click **[🔑 Get Section ID](https://whats-app-linker--sherrylaal2.replit.app)** button above
2. Enter your WhatsApp number
3. Get 8-digit pairing code
4. On your phone: **WhatsApp → Settings → Linked Devices → Link with phone number**
5. Enter the pairing code ✅

### Step 5 — Run Locally

```bash
node index.js
```

### Step 6 — Deploy on Railway

<div align="center">

[![🚂 Deploy on Railway](https://img.shields.io/badge/🚂%20One%20Click%20Deploy-Railway-8B00FF?style=for-the-badge&logo=railway&logoColor=white)](https://railway.app/new/template?template=https://github.com/M-M-MALIKxMD/marco-malik_md)

</div>

1. Click **Deploy on Railway** button above
2. Connect your GitHub account
3. Add Environment Variables (from `.env.example`)
4. Deploy → Open Logs → **Scan QR or use Pairing Code**
5. Bot goes live! ✅

**Add Volume for permanent session:**
- Railway → **+ New → Volume**
- Mount Path: `/app/auth_info`

### Step 7 — Deploy on Heroku

<div align="center">

[![☁️ Deploy on Heroku](https://img.shields.io/badge/☁️%20One%20Click%20Deploy-Heroku-430098?style=for-the-badge&logo=heroku&logoColor=white)](https://heroku.com/deploy?template=https://github.com/M-M-MALIKxMD/marco-malik_md)

</div>

```bash
heroku login
heroku create marco-malik-bot
heroku stack:set container
heroku config:set BOT_NAME="Marco Malik MD Bot" OWNER_NUMBER="923xxxxxxxxx" OPENAI_API_KEY="sk-xxx"
git push heroku main
```
